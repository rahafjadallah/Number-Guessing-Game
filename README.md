## 📌 About The Project

Number Guessing Game is a simple interactive JavaScript program that generates a random number between 1 and 100. Players are challenged to guess the correct number by entering their guesses through a prompt window. After each guess, the program provides feedback using alert messages to help players determine whether their guess is too high or too low. The game continues until the correct number is guessed and displays the total number of valid attempts.

## ✨ Features

- Generate a random number between 1 and 100.
- Allow users to enter guesses using `window.prompt()`.
- Provide hints when the guess is too high or too low.
- Validate user input.
- Prevent invalid numbers and out-of-range guesses from counting as attempts.
- Count the number of valid attempts.
- Display a success message when the correct number is guessed.
- Interactive alerts using `window.alert()`.

## 🛠️ Technologies Used

- JavaScript (ES6)

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Enter a number between 1 and 100 in the prompt window.
5. Follow the hints until you guess the correct number.
